# Piano Follow-Along

A practice page that listens to a piano through the microphone and follows along with a MIDI file. It shows the melody as falling notes over a keyboard and moves forward only when the right note is played.

Open it at https://heshmati-uw.github.io/piano-follow-along/

## Shared songs

MIDI files in the `songs` folder appear under "Shared songs" in the app for anyone to pick. The repository owner can save files to that folder from inside the app by adding a GitHub access token under "Saving to the shared library". The token needs Contents read and write on this repository only, and it is kept in the owner's browser.

This repository is public, so every file in `songs` can be downloaded by anyone.
